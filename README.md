# Interview Prep AI

An AI-powered mock interview application built using React, TypeScript, and modern web technologies. The platform helps users practice technical interviews, answer interview questions, and improve their confidence through simulated interview sessions.

## Features

* AI-powered mock interview experience
* Interactive interview sessions
* Real-time question and answer flow
* Interview result and feedback screen
* Clean and responsive user interface
* Built with TypeScript and React
* Fast development and build process using Vite

## Tech Stack

### Frontend

* React
* TypeScript
* Vite
* Tailwind CSS
* TanStack Router

### Development Tools

* ESLint
* Prettier
* npm

## Installation

Clone the repository:

```bash
git clone https://github.com/JASWANTH-JAS-PNG/interview-prep-ai.git
```

Navigate to the project folder:

```bash
cd interview-prep-ai
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```
